# 微信读书 → Techo

入口：个人兴趣 → 微信读书笔记。

1. 打开 https://weread.qq.com/r/weread-skills，登录后创建 API Key。
2. 在 Techo 的“连接微信读书”里填写 API Key，点击“验证并连接”。不要把 Key 提交到 GitHub 或聊天中。
3. 点击“同步书架”，再点击“同步全部笔记”；也可打开单本书，点击“更新本书笔记”。
4. 画廊 / 表格可以切换，支持书名、作者、分类搜索和阅读状态筛选。单本书按章节展示划线与个人想法，支持导出 Markdown。
5. 网站内的“我的阅读心得”独立存储，同步源笔记不会覆盖；返回书架前也会保存心得。

## 数据与凭据

使用腾讯官方只读 Gateway，依据 Tencent/WeChatReading 的 shelf、book、notes 文档实现；未安装或运行第三方 MCP/SDK，也不依赖 Notion 授权。

请求通过现有站点访问验证和 X-Sync-Code 用户验证。API Key 存储在独立 D1 表中，使用 AES-GCM 加密，附加认证数据绑定同步账号；密钥来自 WEREAD_ENCRYPTION_KEY，未指定时使用已有 SESSION_SECRET 派生。凭据不进入前端构建、通用 settings 或响应。加密密钥轮换后需重新连接微信读书。

源书籍元数据和章节笔记，与个人心得分别保存。重复同步只更新源字段。书架同步保留历史已导入的书，不自动删除。当前画廊范围为电子书；有声专辑数量在同步结果中单独说明。

## 验证

- npm test：6 项测试通过，覆盖加密账号隔离、Gateway 参数和错误脱敏、分页、1% 进度、停滞游标、SQLite 重复同步保留心得、用户记录隔离和跨站写入拒绝。
- npm run lint、npm run build 和 Wrangler Pages Functions 编译通过。
- 隔离样例后端浏览器检查：搜索、画廊/表格切换、章节划线/想法、心得保存并再次同步保留、Markdown 下载及内容核对。
- 手机 390 × 844：布局无横向溢出，按钮换行、原文和想法正常显示。
- 线上 SESSION_SECRET 已存在；上线后需要用户本人连接 API Key 才能验证真实账号的数据。

## 接口边界

手动同步；尚未配置定时同步。个人想法最多处理 20 页，每页 100 条，分页异常或超限时报告错误而不覆盖已保存笔记。上游响应限制 2 MiB，单本章节内容限制 800 KB。授权过期时在网站内更新 API Key。官方接口不能导出书签内容，展示的笔记条数是已导出的划线与想法条数。
